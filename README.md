# Pokémon Yellow Color

A Game Boy Color enhancement of the English Pokémon Yellow, built from the
pret disassembly. The intended deliverable is a BPS patch for a user-supplied ROM.

This project preserves Yellow's maps, story, mechanics, original artwork, and
Pikachu follower, while adding individually colored terrain and characters.

## Base ROM

- English USA/Europe Pokémon Yellow, 1,048,576 bytes.
- SHA-1: `cc7d03262ebfaf2f06772c1a480c7d9d5f4a38e1`
- ROM dumps, compiled ROMs, saves, and local tools are excluded from Git.
